# Stage 1: Earthquake Spatial Visualization using QGIS

This project focuses on visualizing earthquake events that occurred between **2000 and 2020** using QGIS. The aim was to create a thematic map and identify the **Top 10 locations with the highest earthquake-related fatalities** through spatial visualization.


## Objective
- Visualize earthquake locations on a map.
- Identify the Top 10 locations with the highest death count.
- Learn the basic GIS workflow using QGIS.

## Tools Used
- QGIS
- Earthquake Dataset (2000–2020)


### 1. Import Data
- Loaded the earthquake dataset into QGIS as a point layer.

### 2. Apply Symbology
- Customized the map symbols to clearly display earthquake locations.

### 3. Add Labels
- Labeled the Top 10 locations with the highest earthquake fatalities.

### 4. Export Map
- Created a print layout and exported the final map as a PNG image.

## Key Insights
- Mapped earthquake events from **2000–2020**.
- Highlighted the **Top 10 locations with the highest death toll**.
- Demonstrated how GIS can be used to visualize and communicate spatial data effectively.
